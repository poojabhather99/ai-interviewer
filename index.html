Adaptive interview with scoring

Start an interview, answer the questions, and get a scored report. Sessions are stored in SQLite (in your browser's memory here).

This page runs the project's actual Python source in your browser (via Pyodide). Nothing is sent to a server. View the code on GitHub.

Without an API key the questions come from a fixed five-step ladder; this page uses that offline mode. Scores measure the form of an answer (depth, structure, specifics), not whether it is technically correct. The hosted API (FastAPI) is in the repo; this page runs its interview and scoring logic directly.
